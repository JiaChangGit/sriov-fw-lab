SR-IOV Controller Firmware & Platform Lab

本版範圍為 M0–M3／T01–T10，以 16 GB RAM 筆電、WSL2 Ubuntu 26.04 與 QEMU TCG 執行。

可攜 C core 管理 VF 狀態、資源與 mailbox；QEMU 提供 PF/VF、DMA、MSI-X 與 reset 模型。 Linux guest 透過 PF driver、VFIO tenant 及 vIOMMU 驗證隔離與生命週期；UEFI probe 驗證開機交接。

  • 功能範圍與驗收條件
  • 暫存器與 ABI
  • 控制協定與資料路徑
  • 實測結果與限制
  • 建置與系統分析教材

不提供 M4/M5、KVM、KCSAN、實體 passthrough、刷寫或硬體效能驗證。 reserved update opcode 回覆 UNSUP，不表示已實作更新功能。

檔名保留供既有驗證工具記錄規格雜湊；現行要求以連結的文件為準。
